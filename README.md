# Uber XL Power BI Dashboard 🚗📊

An interactive **Power BI dashboard** designed to analyze Uber XL ride performance, bookings, revenue, distance, and customer/driver ratings.

## 📌 Project Overview

This dashboard provides a clear overview of Uber XL operations through interactive KPIs and visualizations. It helps analyze booking trends, revenue performance, ride status, and customer experience across different months.

## 📊 Key KPIs

* **Completed Bookings:** 2,783
* **Lost Bookings:** 1,666
* **Revenue:** 2M
* **Total Distance:** 74.31K
* **Average Distance:** 24.40
* **Average Customer Rating:** 4.40
* **Average Driver Rating:** 4.24

## 📈 Dashboard Insights

* Monthly trend of completed bookings
* Monthly revenue analysis
* Revenue by vehicle type
* Completed, cancelled, and incomplete ride analysis
* Top pickup and drop locations
* Customer and driver rating analysis
* Monthly and quarterly performance views

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Data Cleaning & Transformation**
* **Data Visualization**

## 🎯 Objective

The main objective of this project is to transform raw Uber ride data into an interactive business intelligence dashboard that makes it easier to understand **booking performance, revenue trends, operational efficiency, and customer satisfaction**.

## 📷 Dashboard Preview

The dashboard includes interactive filters and visualizations that allow users to explore Uber XL performance from different perspectives.

## 💡 Key Learning

Through this project, I gained practical experience in **data cleaning, KPI development, DAX calculations, dashboard design, and business-oriented data analysis using Power BI**.
